组详情手机：左右 16px 井太宽

截图是 390 宽的手机。tiles / tip / search / chips / .mcc-system-list 各写了一遍 padding/margin: 0 16px。两边共 32px 空白，再加卡片内 10px，名字还要让给两个 28px 按钮， 于是 “Google Chrome · 55341” 被ellipsis成 “Google Chrome · 5…”。

结论：只在 @media (max-width: 720px) 里把 .mcc-system 这一页的水平 inset 从 16px 收到 8px（tiles、list、ptip、ptools、sub、section-header）。 桌面仍 16px。不贴边（0px），也不动卡片内部 padding 和按钮尺寸。
