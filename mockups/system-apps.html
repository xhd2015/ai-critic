Apps 的定义

  • macOS：/Applications、~/Applications 下的 .app bundle（用户安装的）。 /System/Applications 默认隐藏，可用 “Show system apps” 打开。
  • Linux：freedesktop .desktop 条目（/usr/share/applications、 ~/.local/share/applications、Flatpak / Snap 导出目录），即启动器里能看到的那些。
  • Windows：开始菜单快捷方式（%ProgramData% 与 %APPDATA% 下的 Start Menu\Programs\**\*.lnk）+ 注册表 Uninstall 项，即“已安装程序”。

图标管线

  • 服务端 GET /api/server/apps/icon?path=… 返回 PNG/SVG，浏览器 <img> 懒加载；不在 2s 的 processes 轮询里塞 base64。
  • macOS：Info.plist 的 CFBundleIconFile → .icns； 直接抽 ic07/ic08 里内嵌的 PNG（纯 Go、零 fork），失败再退回 sips。
  • 磁盘缓存按 bundle 路径 + mtime 取 key，一次转换长期复用。
  • 没有图标的 bundle（本页的 ai-critic-macos.app 就没有 Resources）→ 字母色块兜底。

数据从哪来

  • 新增 GET /api/server/apps：枚举已安装应用，服务端缓存（含 mtime 校验），只在 Apps 视图打开时拉取。
  • 「运行中 / 进程数 / CPU / 内存」= 现有 processes 快照里 cmd 落在该 bundle 内的进程聚合， 浏览器端 join，保持 2s 实时。
  • 空闲应用不参与轮询；不 fork、不 du、不 plutil，避免重演 git 子进程风暴。
