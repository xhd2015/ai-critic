System 顶栏：返回箭头和标题要对齐

/home/system 顶栏里 BackIcon（20×20 SVG）塞进为文字准备的 .mcc-back-btn （font-size: 14px; padding: 4px 8px; margin-right: 8px，没有 flex 居中）。 SVG 按文字基线排，箭头的视觉中心和 20px 的 “System” 对不齐。红/绿线是同一条几何中线。

结论：.mcc-back-btn:has(svg) 改成 28×28 的 inline-flex 图标按钮，SVG display:block， h2 line-height: 28px。去掉 System / group / pid / disk 页上的 inline padding: 4。 纯文字的 ← Back 按钮不走 :has(svg)，保持原样。

规格

项目现在改后
.mcc-back-btn 为 “← Back” 文字准备：font-size: 14px; padding: 4px 8px; margin-right: 8px，不是 flex 统一 display: inline-flex; align-items: center; justify-content: center。:has(svg) 时 width/height: 28px; padding: 0; margin: 0; line-height: 0
SVG inline，基线对齐，20×20 display: block，仍 20×20，在 28 盒里居中。给 aria-hidden
h2 20px / weight 600，行高浏览器默认 ≈ 24 加 line-height: 28px，和按钮盒同高
inline style SystemView / SystemGroupPage / SystemProcessPage / DiskView / ManageServerView 各写一遍 padding: 4 删掉这些 inline padding。间距用 header gap
文字返回按钮 ← Back、← 仍用同一 class :has(svg) 不命中，padding / 字号保持原样，只多了 flex 居中（无害）
不改 BackIcon 的 path。折线 15,18 9,12 15,6 在 24 视口里几何居中。 偏的是按钮盒子，不是箭头形状。
