Browser：历史前进/后退、关闭当前标签、二级键盘

四个 frame：A 新增的导航行（VIEW 模式）、B 切到 CTRL 时键盘保持关闭、C 一级键盘（维持现状，只多一个入口）、 D 二级键盘（Ctrl/Alt/Delete、复制粘贴、右键菜单、常用快捷键）。

假设与已核实的能力：
1. 前进/后退走 Page.getNavigationHistory + Page.navigateToHistoryEntry——已在真实标签页上验证可用（后退一步成功）。
2. 关闭当前 tab 走现有 Target.closeTarget polyfill（sweep 已在用），tab-close-confirm-v1 负责确认。
3. 组合键已具备：InputEvent.Modifiers 支持 ModAlt=1 / ModCtrl=2 / ModMeta=4 / ModShift=8。
4. 右键菜单用 Input.dispatchMouseEvent 的 button:"right"（长按菜单在页面层弹出，与桌面一致）。
5. 复制/粘贴用 Input.insertText 与 Runtime.evaluate(navigator.clipboard)；另保留组合键 Ctrl/Cmd-C、Ctrl/Cmd-V 作为兜底。

常用快捷键
Ctrl / Alt / ⌘ 为粘滞修饰键：点亮后按下一个普通键即组合发送，随后自动熄灭。点亮 Ctrl 时按 A 等于 Ctrl-A。

二级键盘分三段：修饰键（Ctrl / Alt / ⌘ / Shift / ⌦ Delete，粘滞可叠加）、 动作（Copy / Paste / 右键菜单 / 全选）、常用快捷键（Ctrl-A/E/C/V、⌘-A/C/V 一键直发）。 ⌦ del 与 ⌫ 并存：前者删后面字符（Delete/forward），后者删前面。
