Mac 粘贴板：预览 + 复制到 iPhone

粘贴键旁加一个 Peek，展开后读取 Mac 上的粘贴板：显示数据类型、内容预览、以及「复制到 iPhone」和「粘贴进页面」两个动作。 下面按数据类型分组（纯文本 / 富文本 / 图片 / 文件），每组右侧是在 iPhone Safari 里粘贴后的实际样子。

已实测（macOS 26 / 本机）：
✓ 枚举类型：osascript -e 'clipboard info' → 纯文本返回 «class utf8», 15, «class ut16», 32, string, 15, Unicode text； 图片返回 «class PNGf», 93763, «class JPEG», 79017, «class TIFF», 4227614, GIF, BMP, …。
✓ 读富文本：get the clipboard as «class HTML» → «data HTML3C6831…»（hex 编码，剥掉 «data HTML 前缀即可解码）；«class RTF » 同法。
✓ 纯文本可直接 pbpaste；RTF 可用 textutil -convert html 转成 HTML 作退路。
⚠ 同一份内容常有多个 flavor（一张图同时有 9 种编码）。所以「类型」不是一个值，而是一个内容 + 一组可用格式。
⚠ iPhone Safari 的 navigator.clipboard.write() 必须在用户手势内发起： 预览展开时就预取字节，点「复制」时不再 await，否则 Safari 会以 "not allowed" 拒绝。

契约变化

层现在之后
GET /api/browser/clipboard 不存在 新增。返回 {kind, bytes, flavors[], text?, html?, image?{w,h,mime,thumb}}。只读一次、不缓存到磁盘
GET /api/browser/clipboard/raw 不存在 新增。?flavor=png|jpeg|html|rtf|text 返回完整字节，供「复制到 iPhone」与「下载」
server/browser/clipboard.go 只有 pasteText（用客户端传来的文本） 新增 readSystemClipboard()：clipboard info 枚举 → 按优先级 pbpaste / «class HTML» / «class RTF » / «class PNGf» 取值 → hex 解码
ClientMessage（ws） copy / paste / shortcut / tab_close … 新增 clipboard_peek（展开时请求）与 clipboard_paste（取某个 flavor 贴进页面）
BrowserKeysMore.tsx Paste 是一个按钮 + 一个文本框 Paste 拆成「直接粘贴」+「⌄ Peek」；新增 BrowserClipboardPeek.tsx 面板与 useClipboardPeek.ts
本地复制（前端） 无 navigator.clipboard.write([ClipboardItem])；失败时降级 textarea + execCommand('copy')（纯文本）或长按提示（图片）

类型优先级与还原策略

内容识别依据复制到 iPhone 写入1:1 还原程度
富文本«class HTML» 或 «class RTF »text/html + text/plain（RTF 先 textutil 转 HTML）完整：Safari 保留标签与内联样式
纯文本仅 utf8/stringtext/plain完整：换行与空格保留
图片«class PNGf»/JPEG/TIFFimage/png（若无 PNG 则转 PNG）按版本：Safari 16.4+ 支持写图片；否则降级长按保存
文件«class furl»text/plain（路径列表）降级：iPhone 剪贴板无文件概念
表格HTML 里的 <table>text/html + text/plain（TSV）完整：粘进 Notes 保留表格；纯文本目标拿 TSV
