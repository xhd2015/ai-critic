Assumptions · 路由 /home/system/group/Google%20Chrome（name 即现有分组键，encodeURIComponent）· 仍复用 /api/server/processes 快照，不新增后端接口 · 树只在该 Group 成员内连边（跨组父进程以 “root · parent launchd” 标注）· Kill 复用现有 Kill Modal（Graceful / Force Quit），一次只杀一个 pid。

组详情页信息架构

  • Header ← 返回 · Group 名 · live 2s / Pause（与 System 页一致）
  • Tiles Group CPU Σ · Group RSS Σ · Process count · Oldest uptime（即 “2d12h” 这类格式）
  • Hint “Kills are per-process; killing a parent leaves its children running.”（明确语义，不做隐式级联）
  • Tree 组内 pid/ppid 缩进树；每行 title · pid / user · uptime · state / CPU / MEM / ⏻
  • Roots 组内没有可见父进程的节点标 root，并在第二行注明 parent launchd · 1（跨组）或 parent … (outside group)
  • Kill 行内 ⏻ → 现有 Kill Modal（Graceful / Force Quit）；protected 显示 🔒 且禁用
  • 行点击 → 既有 /home/system/pid/:pid 详情页（保留 command / identity / 父链下钻）
  • v1 不做：组级连环 kill（kill subtree）、跨组完整进程树、组内搜索高亮之外的过滤
